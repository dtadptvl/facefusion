3. MODEL METADATA, RELEASE SOURCES, AND LICENSE CONDITIONS
--------------------------------------------------------------------------------
Zero-Bundle Architecture:
No pre-trained model weights are bundled or distributed inside the iFaceFusion
application binary. Models are downloaded on-demand from authorized upstream
release mirrors and verified against cryptographic checksums (CRC32 and SHA256)
before local caching.

Code vs. Weights Licensing Conditions:
Upstream open-source code licenses (e.g., MIT, Apache-2.0, BSD-3-Clause) apply
strictly to the source code and software architectures created by their respective
authors. Model weights are governed by author release covenants and training
dataset terms, and are NOT relicensed under software code licenses. All author-
specified weight restrictions (such as non-commercial research use) are
transparently disclosed below.

Unsupported / Excluded Models:
- InSwapper 128 (inswapper_128): Removed from catalog. Speculative model lacking
  required embedding infrastructure; not supported.
- CodeFormer (codeformer): Defined in catalog with verified CRC32 1456f3ab
  (vendor: sczhou, license: S-Lab-1.0 Non-Commercial Research License), but
  excluded from active catalog offerings (allModels) due to double scalar tensor
  weight inputs unsupported by ONNX Runtime Objective-C.
